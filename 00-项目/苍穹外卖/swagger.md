常用注解

| 注解                | 说明                         |
| ----------------- | -------------------------- |
| @Api              | 用在类上，例如 Controller，表示堆类的说明 |
| @ApiModel         | 用在类上，如 entity，DTO、VO       |
| @ApiModelProperty | 用在属性上，描述属性信息               |
| @ApiOperation     | 用在方法上，说明方法作用               |
