基于双令牌思路实现的用户系统，使用自定义长令牌加 jwt 短令牌的方式，实现的仿 springsecuirty 认证系统。

使用自定义拦截器实现令牌校验
使用自定义注解+aop 的方式实现权限的校验

开设三方认证表，实现微信用户登录，为后续三方登录功能扩展留下空间

使用 redis 存储长令牌，并开设黑名单，管理端添加用户管理功能，可以做到踢人下线和账号封禁

Jwt 短令牌可访问多数低风险接口，降低了 redis 数据库压力
