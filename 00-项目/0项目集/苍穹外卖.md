苍穹外卖（Java 后端项目）
S（背景）：外卖服务平台，需支持微信小程序登录、高频菜单查询、订单催单等场景，要求高响应、低延迟。

T（任务）：实现用户鉴权、菜品/套餐缓存、实时催单功能。

A（行动）：
Spring Boot 构建后端，MyBatis + PostgreSQL 持久化
Redis 缓存菜品与套餐，降低数据库压力
JWT 实现微信小程序登录与鉴权
WebSocket 支持催单消息实时推送

R（结果）：
查询响应时间显著降低，数据库负载减少约 40%
催单消息延迟 < 1 秒
完成完整的小程序登录与鉴权流程
