## **三、核心功能与实现**

示例：
1. **部门管理**：
    - 支持部门的**增删改查**（CRUD）操作。
    - 支持部门**层级结构管理**，可创建子部门，形成树状结构。
    - 数据持久化层通过 MyBatis-Plus 简化开发，使用 `Service` 层封装业务逻辑。
2. **员工管理**：
    - 员工信息的完整 CRUD，包括姓名、工号、所属部门、入职时间等。
    - **员工经历管理**：关联员工的工作经历记录（如岗位变更、项目经历），支持多经历添加与查看。
    - 使用 MP 的动态 SQL 功能简化复杂查询（如按部门、时间范围筛选）。
3. **登录与权限控制**：
    - 基于 **JWT + 拦截器** 实现认证与授权：
        - 用户登录成功后，服务端签发 JWT 令牌，客户端后续请求携带 token。
        - 自定义拦截器拦截所有请求，解析 token 并验证权限，拒绝未授权访问。
    - 用户角色区分（如管理员、普通员工），不同角色拥有不同操作权限。
4. **全局异常处理**：
    - 通过 `@ControllerAdvice` 实现全局异常捕获，统一处理系统异常（如参数校验异常、数据库异常）。
    - 封装统一返回结果类，定义成功/失败响应格式，提升接口规范性。
5. **其他**：
    - 使用 Lombok 简化实体类代码（`@Data`、`@Builder` 等注解）。
    - 通过 Logback 配置日志输出，记录系统运行信息，便于问题排查。

## **四、技术亮点与难点解决**
示例：
1. **权限控制设计**：
    - 使用 JWT 替代 Session，解决分布式环境下 Session 共享问题，提升系统扩展性。
    - 通过拦截器链实现细粒度权限控制，灵活配置不同 URL 的访问权限。
2. **数据安全**：
    - 用户密码存储采用加密算法（如 BCrypt），避免明文存储风险。
    - 接口请求通过 token 验证，防止未授权访问。
3. **开发效率提升**：
    - 利用 MyBatis-Plus 的代码生成器快速生成 CRUD 基础代码，减少重复工作。
    - 全局异常处理器统一处理异常，避免到处写 `try-catch` 代码。
4. **难点与解决**（可选，体现你的思考过程）：
    - **问题**：员工经历与员工表的关联设计。
    - **解决**：通过数据库外键关联，在实体类中使用 `@TableField` 注解配置关联关系，利用 MP 的联表查询功能实现数据获取。
    - **问题**：JWT 令牌过期处理。
    - **解决**：在拦截器中判断 token 有效期，过期后返回特定状态码，前端提示用户重新登录。
