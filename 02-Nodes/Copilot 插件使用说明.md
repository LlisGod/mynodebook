## 更新补充

### 基础问答功能设置

不过最近这个插件的更新比较频繁，不少功能的位置都有所变化，我在这里简要说说，你需要结合前面两篇参考文章一起学习。

1. 点击 Add Custom Model 可以添加自己的 API Key 
2. API Key 的设置方法依然可以参考这篇文章：[点我](https://eryinote.com/post/1683)
3. 配置完毕后，就可以跟 Copilot 进行对话了

### 知识库设置

这部分设置 Embedding Models 的位置也有变化，具体如下图所示。然后设置方法也可以参考这篇文章：[点我](https://eryinote.com/post/1685)
