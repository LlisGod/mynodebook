#### **3. 开发阶段（分模块突击）**
**典型工作流（以评论模块为例）**：
1. **后端先行（2 小时）**：
   ```javascript
   // 最小化API实现
   app.post('/posts/:id/comments', async (req, res) => {
     const comment = await prisma.comment.create({
       data: {
         content: req.body.content,
         postId: parseInt(req.params.id)
       }
     });
     res.json(comment);
   });
   ```

2. **前端速攻（1.5 小时）**：
   ```vue
   <!-- 极简评论组件 -->
   <script setup>
   const content = ref('');
   const submit = async () => {
     await fetch(`/posts/${postId}/comments`, {
       method: 'POST',
       body: JSON.stringify({ content: content.value })
     });
     content.value = '';
   };
   </script>

   <template>
     <textarea v-model="content"></textarea>
     <button @click="submit">发布评论</button>
   </template>
   ```

3. **即时测试（0.5 小时）**：
   ```bash
   # 同时启动前后端
   concurrently "npm run dev" "nodemon server.js"
   ```

#### **4. 测试策略（自动化优先）**
**分层测试方案**：

1. **组件级测试**（Vitest + Testing Library）
   ```javascript
   test('评论提交后清空输入框', async () => {
     render(CommentEditor);
     await user.type(screen.getByRole('textbox'), '测试内容');
     await user.click(screen.getByText('发布评论'));
     expect(screen.getByRole('textbox')).toHaveValue('');
   });
   ```

2. **API 测试**（使用 curl 快速验证）
   ```bash
   curl -X POST http://localhost:3000/posts/1/comments \
        -H "Content-Type: application/json" \
        -d '{"content":"测试评论"}'
   ```

3. **E 2 E 测试**（Playwright 录制）
   ```javascript
   test('完整评论流程', async ({ page }) => {
     await page.goto('/posts/1');
     await page.fill('textarea', '自动化测试评论');
     await page.click('button:has-text("发布评论")');
     await expect(page.locator('.comment-list')).toContainText('自动化测试评论');
   });
   ```

### **四、避坑指南（单人专属）**

#### **1. 时间管理陷阱**
- **时间盒工作法**：每个功能模块限时 3 小时
- **番茄钟配置**：25 分钟开发 → 5 分钟测试 → 循环

#### **2. 代码质量保障**
- **即时 Lint**：保存时自动格式化（ESLint + Prettier）
- **架构约束**：目录结构模板
  ```
  /src
    /api    # 后端路由
    /client # 前端代码
    /prisma # 数据库模型
  ```

#### **3. 需求控制策略**
- **功能开关**：通过环境变量控制特性
  ```javascript
  if (process.env.FEATURE_COMMENT === 'on') {
    app.use('/comments', commentRoutes);
  }
  ```
- **版本降级**：复杂功能替换为静态数据
  ```javascript
  // 先写死数据快速验证
  const mockPosts = [{ id: 1, title: '测试帖子' }];
  ```

### **五、单人开发心法**
1. **垂直开发法**：完成登录→发帖→评论的完整闭环，再扩展其他功能  
2. **最小化原则**：数据库字段不超过 5 个，API 参数不超过 3 个  
3. **物理进度可见**：使用燃尽图跟踪进度  
4. **反完美主义**：先实现「能用」，再优化「好用」  

---

**典型案例**：  
- **第 1 天**：完成用户注册/登录 + 基础发帖  
- **第 3 天**：实现评论功能 + 基本 UI  
- **第 1 周**：部署上线 + 邀请 10 个用户测试  
- **第 2 周**：根据反馈优化 + 增加通知功能

| 传统流程         | 单人优化流程       | 效率提升        |

**终极建议**：单人全栈开发如同**一人乐队**——不需要交响乐的复杂编排，但要精通几件核心乐器（关键技术栈），通过**循环迭代**快速创作完整乐曲（可运行系统）。记住：完成比完美更重要，交付比设计更优先！
