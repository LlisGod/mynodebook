使用 sql 中的 limt 字段，指定分页开始项目和分页大小，就可以查询到对应页面

第一个参数为偏移量，第二个参数为页大小
比如，规定页面大小为 10，查询第一页的 sql 语句是
```sql
select * from table limit 0,10; 
%% 或者 %%
select * from table limit 10 offset 0
```
不同数据库的语法可能不同

# 缺陷和改进

由于需要的字符是偏移量和页面容量

在后端需要进行一部运算得到偏移量=（页面数\*页面大小-1）
这是一种非常不优雅的行为

所以 [[PageHelper]] 以及 [[Mybatis-plus]] 的分页组件可以自动实现这一个行为
