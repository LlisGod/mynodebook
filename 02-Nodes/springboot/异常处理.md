## 全局异常处理器

使用 **@RestControllerAdvice** 注解定义全局异常处理器类

使用 **@ExceptionHandler** 注解定义错误处理方法
```java
@Slf4j  
@RestControllerAdvice  
public class GlobalExceptionHandler {  
    @ExceptionHandler(Exception.class)  
    public ApiResponse<String> handleException(Exception e) {  
        log.error("全局异常处理", e);  
        return ApiResponse.error(500, "出错了"+e.getMessage());  
    }  
}
```
如果定义多个异常处理方法，先寻找对应错误处理，则按照子类优先的原则向上寻找

## 自定义错误

#### 自定义业务异常 (BusinessException)

为了让业务逻辑的错误也能被统一优雅地处理，我们可以自定义一个异常类。它通常继承自 `RuntimeException`，以便于触发事务回滚。

```java
// 自定义业务异常
Public class BusinessException extends RuntimeException {
    Private Integer code;
    
    public BusinessException(Integer code, String message) {
        super(message);
        this.code = code;
    }
    
    public Integer getCode() {
        return code;
    }
}```
