 两个相互关联的表的插入
 需要注意事务管理，字段回显等

比如员工新增以及员工工作经历新增

### 事务管理

在 service 层加上事务注解，保证两项插入同时生效

### 非空检验

如员工工作经历在员工对象的工作经历列表中
此时需要判断列表是否为 null，是否为空
### Id 回显

员工 id 是数据库自增的，所以要在员工插入后拿到员工 id 回显，逐条为工作经历的员工 empId 字段赋值，

对于 Mybatis，加上@Options 注解就行，返回类型改为 int，数据会自动插入对象,service 层不用改动
Mp 则更简单，不做赘述

```java
@Insert("insert into employee (username,name,gender,phone,avatar_url,dept_id,entry_date,create_time,update_time)" +  
        "value (#{username},#{name},#{gender},#{phone},#{avatarUrl},#{deptId},#{entryDate},#{createTime},#{updateTime})")  
// 数据库id回填，保证工作经验员工id与实际员工id一致  
@Options(useGeneratedKeys = true, keyProperty = "id")  
int insert(Emp emp);
```

用如下类似语句插入工作经历列表即可
```java
emp.getEmpExprs().forEach(expr -> expr.setEmpId(emp.getId()));
```
