# 网页排版的核心思路

	在网页中，不同的元素放在不同的位置，如侧边栏、搜索框。浏览器放置这些元素的底层思想就是盒模型

盒模型是 CSS 中用来布局的核心概念，每个元素都像一个盒子，由四部分组成：

1. **内容区**（Content）
   - 最内层，显示文本/图片等实际内容
   - 通过 `width/height` 设置尺寸

2. **内边距**（Padding）
   - 内容与边框的缓冲区域
   - 设置：`padding`

3. **边框**（Border）
   - 包裹内容和内边距的可见边界
   - 设置：`border-width/style/color`

4. **外边距**（Margin）
   - 盒子与其他元素之间的透明隔离带 
   - 设置：`margin`

![盒模型示意图](https://www.w3schools.com/css/box-model.gif)

总宽度 = width + padding左右 + border左右 + margin左右  
（可通过 `box-sizing: border-box` 改变计算方式）

例如：
```css
div {
  width: 300px;
  padding: 20px;
  border: 5px solid black;
  margin: 10px;
}
```
实际占位宽度 = 300 + 40 + 10 + 20 = 370px
