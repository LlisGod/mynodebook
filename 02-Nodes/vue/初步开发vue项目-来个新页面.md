用脚手架创建一个空的 vue 项目后，该怎么把他变成自己的项目

# 项目架构

./src 目录是我们工作的目录

里面有
- main. Js：启动程序
- App. Vue：最外层组件（根组件）
- Views：页面组件文件夹
- Router：路由文件夹
- Components：组件文件夹
- Stores：储存文件夹
- Assets：样式文件夹

# 写个单页面

在 views 中新建一个.vue 文件，写上你的页面代码

一个约定俗成的规矩，在你的组件外层包裹一个<div id/class=“组件名称”>

可以先写一些简单的概念代码，展示这个页面应该实现的功能


## 现在，页面准备好了

但是该怎么展示你的页面呢？

### 注册路由
首先，在 router 中的 index. Ts 中你会看到已经定义好的几个路由
仿照样式为你新建的页面注册路由

将网站切换到你的新路由，你会发现，页面的右半边变成了你的页面

回到 app. Vue，看到两个奇特的组件

<nav>标签是导航栏，里面的 routerlink 组件可以实现路由的点击跳转
<RouterView>组件是一个展示框，展示路由指向的页面

我们检查就会发现，app. Vue 默认设定的样式为左右分别为导航栏，内容栏
更改后，页面变成想要的样子
（实际上你可能还要看看 Assets 内的全局样式）

到此为止，你掌握了 vue 最简单的单页面组件的使用
