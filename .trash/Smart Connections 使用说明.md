## 自动关联相关

当你安装完这个插件后，一般来说它就会使用默认设置来对笔记库进行处理，等到嵌入处理完毕，就可以在 Smart Connection 中看到关联的笔记了。

如果有新增的笔记，就重启一下 Obsidian， 就会对新增笔记进行嵌入处理。

##  API Key 配置方法

这个插件也有类似 Copilot 的问答窗口，不过需要配置自己的 API，方法如下。

 1. 使用快捷键 ctrl+P 打开 Obsidian 的命令窗口
 2. 输入 Smart Connection 关键词，找到 `open smart chat view` 选项并打开
 3. 右上角会有一个齿轮图标，点击打开
 4. 填写 API Key。推荐使用 OpenRouter，最便捷稳定，只需要在齿轮最下方填写 OpenRouter 的 API Key 就可以用了。
 5. OpenRouter Key 的申请教程：[点我](https://eryinote.com/post/1695)。
