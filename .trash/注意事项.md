如果你提交给 DeepSeek 的文章太多，有可能它无法一次性读完，会导致生成失败。如果出现这样的问题，建议换一个上下文窗口更长的模型，例如 Google 的 Gemini 2.0。

那么如何获取 Gemini 2.0 的 API Key 呢？有两种方法

1. 使用 [OpenRouter](https://eryinote.com/post/1695)，但是 OpenRouter 需要美元支付，需要你有一张支持外币的信用卡
2. 使用其他第三方中转的 API 平台，例如下面这些。如果要充值，建议先充值最小额度试试。有条件建议还是用 OpenRouter
	- [兔子 API](https://api.tu-zi.com/register?aff=dZkl/)
	- [API2D](https://api2d.com/r/231461/)
