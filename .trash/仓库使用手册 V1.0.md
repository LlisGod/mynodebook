# 完善的标签系统
根据**MECE原则**：相互独立，完全穷尽（Mutually Exclusive, Collectively Exhaustive）
建立标签森林
各个树之间正交，除了base树，其他树的子标签可以在文件有多个（难以做到严格互斥，比如全栈和安全开发）设计自己的树时请求助ai尽量保证互斥性
- base标签树：基本树（确定笔记的基本类型，对于每个笔记唯一，严格互斥）
	- NODE：笔记
	- Blueprint(Superme)：展望 蓝图（比如如何成为一个养花高手的ai回答）
	- Plan：计划、任务清单（确定要成为养花高手后拆解出的行动指南、任务清单）
	- Dashboard：主页（我的技能树，我的人设，我的六维评价指标）
	- MOC：知识目录（前端知识汇总）
	- Project：项目记录（课程主页，开发日志啥的）（可以总结为博客文章发出）
- 其他标签树如
	- 邻域树
		- cs
			- 全栈
				- 前端
				- 后端
			- 游戏开发
				- unity
				- ue
			- 人工智能

**优势**：便于管理和查找，无需在初期建立复杂的文件夹结构，节省工程成本，使用标签管理插件可以快速批量处理对应文件
不同标签树各司其职，相互解耦合，便于维护
