# 灾害数据处理系统项目报告

## 1. 项目概述

本项目构建了一个集成双引擎预测模型的灾害数据处理系统，旨在为城市灾害防控提供智能化决策支持。系统通过大语言模型 (LLM) 处理文本灾害描述，同时使用时空图神经网络 (STGNN) 分析气象数据，实现了对灾害风险的全面评估。项目成功模拟了 2023 年 7 月 11-14 日成都市极端降雨场景，验证了系统在真实灾害场景下的预测能力。

### 核心功能
- **LLM 风险预测**：处理带地理信息的文本灾害描述
- **STGNN 内涝预测**：分析区级气象数据（6 小时窗口）
- **数据存储与检索**：记录历史预测结果
- **RESTful API 服务**：提供标准化数据接口
- **模拟测试系统**：支持极端场景验证

## 3. 关键技术实现

### 3.1 双引擎预测系统

#### LLM 风险预测引擎
- **输入处理**：
  - 地理信息标准化（区级定位）
  - 文本关键信息提取
  - 历史数据关联
- **预测流程**：
  1. 构建结构化提示词
  2. 调用 DeepSeek API
  3. 解析 JSON 格式结果
  4. 风险等级映射（低、中、高、极高）
- **优势**：自然语言理解能力强，适应模糊描述

#### STGNN 内涝预测引擎
- **模型架构**：
  ```mermaid
  graph LR
  A[输入数据] --> B[空间图卷积层]
  B --> C[时间卷积层]
  C --> D[特征融合]
  D --> E[全连接层]
  E --> F[风险评分输出]
  ```
- **技术特性**：
  - 滑动窗口机制（6 小时数据）
  - 区域关系图建模
  - 多气象特征融合（降雨量、湿度等）

## 6. 技术挑战与解决方案

### 挑战 1：时空数据对齐
**问题**：气象站点数据时间粒度不一致  
**解决方案**：开发时间插值算法  
```python
# scripts/data_process/fix_hour_values.py
def interpolate_hourly(data):
    # 创建完整时间序列
    full_index = pd.date_range(start=start_date, end=end_date, freq='H')
    # 线性插值填补缺失值
    return data.reindex(full_index).interpolate()
```

### 挑战 2：LLM 输出标准化
**问题**：API 返回自由文本需结构化  
**解决方案**：设计输出模板+正则提取  
```python
# src/models/llm/output_parser.py
def parse_llm_response(text):
    pattern = r'\{.*?"risk_level":.*?\}'
    match = re.search(pattern, text, re.DOTALL)
    return json.loads(match.group()) if match else None
```

### 挑战 3：实时数据维护
**问题**：STGNN 需要 6 小时连续数据  
**解决方案**：环形缓冲区实现  
```python
# src/models/stgnn/data_window.py
class CircularBuffer:
    def __init__(self, size=6):
        self.buffer = [None] * size
        self.index = 0
        
    def add(self, data):
        self.buffer[self.index] = data
        self.index = (self.index + 1) % len(self.buffer)
```

### 挑战 4：系统资源优化
**问题**：模型加载内存占用高  
**解决方案**：懒加载+资源共享  
```python
# 应用启动时只加载轻量组件
llm_engine = None
stgnn_engine = None

@app.before_first_request
def initialize_models():
    global llm_engine, stgnn_engine
    llm_engine = LLMPredictor()
    stgnn_engine = STGNNPredictor()
```
