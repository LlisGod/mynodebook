##  技术栈选择 ：
- 后端框架：Springboot
	- 持久层：mybatis-plus
- 数据库：Postg
- OSS：阿里云

## 数据库表结构

- 部门表：
	 - 部门 id
	 - 部门名称
	 - 创建时间
	 - 最后修改时间

- 员工表
	- 员工 id
	- 员工名称
	- 员工姓名
	- 员工性别
	- 员工电话
	- 员工密码
	- 员工头像链接
	- 员工部门 id
	- 创建时间
	- 最后修改时间

- 员工工作经历表
	- Id
	- 员工 id
	- 公司
	- 起始时间
	- 结束时间

- 学生表
	- 学生 id
	- 学生名称
	- 学生姓名
	- 学生性别
	- 学生所属班级
	- 学生最高学历
	- 学生电话
	- 学生头像链接
	- 创建时间
	- 最后修改时间

- 班级表
	- 班级 id
	- 班级名称
	- 班主任（员工）id
	- 创建时间
	- 最后修改时间
