   - 包含问题和答案两部分。

### 二、创建卡片
#### 2.1 问答卡片

1. **单行基础卡片**：
   - 使用 `::` 分隔问题和答案。
   - 示例：`问题::答案`。

2. **单行双向卡片**：
   - 使用 `:::` 分隔两部分，生成两张卡片。
   - 示例：`信息1:::信息2`。
   - 效果：分别生成 `信息1 -> 信息2` 和 `信息2 -> 信息1` 的卡片。

3. **多行基础卡片**：
   - 使用 `?` 分隔问题和答案，支持多行文本。
   - 示例：
     ```
     问题文本
     ?
     答案文本
     ```

4. **多行双向卡片**：
   - 使用 `??` 分隔两部分，生成两张卡片。
   - 示例：
     ```
     信息1
     信息2
     ??
     信息3
     信息4
     ```

#### 2.2 填空题
1. **简单填空题**：
   - 使用  ==  标记隐藏部分。
   - 示例：`这是==隐藏部分==的内容`。

2. **多重填空题**：
   - 在一个卡片中定义多个隐藏部分，生成多张卡片。
   - 示例：`这是==第一部分==和==第二部分==的内容`。

3. **提示功能**：
   - 可以为填空题添加提示。
   - 示例：`这是==隐藏部分==^[提示]的内容`。

#### 2.3 卡片分组
- **同级卡片**：由单个卡片定义生成的多张卡片（如双向卡片或多重填空题）。
- **隐藏同级卡片**：在设置中启用后，每天只显示一张同级卡片。

### 四、卡片分类与组织
#### 4.1 使用标签分类
- 默认使用 `#flashcards` 标签标注卡片。
- 支持嵌套标签，例如 `#flashcards/deck1`。

#### 4.2 使用文件夹结构分类
- 插件将文件夹路径映射为卡片分类，例如 `Folder/Subfolder` 对应 `Deck/Subdeck`。

#### 4.3 多个标签与多个分类
- 单个文件中的卡片可以分配到多个分类。
- 示例：
  ```
  #flashcards/deck1 #flashcards/deck2
  问题::答案
  ```

---

### 五、复习与强化
#### 5.1 复习（Review）
- 显示新卡片和到期卡片。
- 通过左侧功能区按钮启动复习。

#### 5.2 强化（Cram）
- 显示所有卡片，包括最近复习过的。
- 可以通过命令选择特定笔记或分类进行强化。

#### 5.3 快捷键
- `空格/回车`：显示答案。
- `0`：重置卡片进度。
- `1/2/3`：分别标记为困难、正常、简单。

---

### 六、高级功能
#### 6.1 自定义填空题格式
- 在设置中创建自定义填空题格式，例如 `{{1::隐藏部分::提示}}`。

#### 6.2 多语言支持
- 支持从右到左（RTL）的语言，例如阿拉伯语、希伯来语。
- 在笔记的 Frontmatter 中添加 `direction: rtl` 以指定文本方向。
