# 概述

高级检索可以通过更精细的限定词，缩小搜索范围，便于找到更精确的结果。比如，查询特定日期，特定类型的网站

# 任务一 ：intitle 的使用

**作用**：限定标题内容
`照片 intitle:信息安全`



# 任务二：site 的使用

使用 site 可以将搜索范围限定在某一个网站中

如 `python site:www.baidu.com`
