## 如何塑造得体仪态

- [ ] 坐下时保持腰背挺直不塌肩
- [ ] 用舌尖轻抵上颚保持自然微笑
- [ ] 交流时注视对方鼻梁三角区


## 如何管理个人形象

- [ ] 选择低饱和度纯色系基础款衣物
- [ ] 定期修剪指甲并保持甲缘光滑
- [ ] 随身携带小瓶衣物除皱喷雾


## 如何经营生活空间

- [ ] 每周更换不同香调的室内扩香
- [ ] 用亚麻餐垫代替塑料桌布
- [ ] 每天下午出门前带上垃圾


## 如何培养言行修养

- [ ] 回复消息前默数三秒再发送
- [ ] 说「请」的频率比「谢谢」多一倍
- [ ] 观看演出时关闭手机光线


## 如何提升日常质感

- [ ] 用钢笔书写购物清单
- [ ] 雨天带长柄伞而非折叠伞
- [ ] 拆快递后用美工刀整齐裁开胶带


## 如何保持精神丰盈

- [ ] 每月学习无用技能（如折纸鹤）
- [ ] 收藏落叶做天然书签
- [ ] 给五年后的自己手写信件
