


## **1. 系统概述**
- **目标**：实现员工信息管理、项目分配与跟踪，提升人力资源管理效率。
- **用户角色**：  
  - 管理员（HR/部门经理）：拥有全部权限  
  - 普通员工：查看个人信息、参与项目  
  - 项目经理：分配/管理项目成员

---

## **2. 核心功能需求**
### **2.1 员工管理（增删改查）**
| 功能          | 详细需求                                                                 |
|---------------|--------------------------------------------------------------------------|
| **添加员工**  | - 必填字段：工号、姓名、部门、职位、邮箱、入职日期<br>- 可选字段：联系方式、技能标签、备注 |
| **删除员工**  | - 软删除（标记离职状态，保留历史记录）<br>- 删除前校验：若员工参与进行中项目，需提示处理 |
| **修改信息**  | - 支持修改基础信息（部门/职位等）<br>- 记录修改日志（操作人、时间）                |
| **查询员工**  | - 多条件筛选：部门/职位/入职时间<br>- 支持导出为 CSV/Excel<br>- 查看员工详情页（含项目历史） |

### **2.2 项目管理**
| 功能                | 详细需求                                                                 |
|---------------------|--------------------------------------------------------------------------|
| **创建项目**        | - 必填字段：项目 ID、名称、负责人、起止日期、优先级<br>- 可选：描述、预算          |
| **分配员工到项目**  | - 从员工列表选择成员并分配角色（如开发/测试/PM）<br>- 校验时间冲突（同一员工不可同时段参与多个项目） |
| **调整项目分配**    | - 动态增删项目成员<br>- 更新成员角色或参与时段                            |
| **项目状态跟踪**    | - 状态标记：未开始/进行中/延期/已完成<br>- 自动计算项目进度（基于任务完成率）      |

### **2.3 综合查询**
- **员工-项目视图**：  
  - 查看某员工参与的所有项目及角色  
  - 查看某项目的所有成员及分工  
- **统计报表**：  
  - 部门人员分布图  
  - 项目负载分析（员工参与项目数量统计）

---

## **3. 非功能性需求**
| 类别       | 要求                                                                 |
|------------|----------------------------------------------------------------------|
| **安全性** | - 角色权限控制（如普通员工不可修改他人信息）<br>- 敏感操作需二次密码验证       |
| **性能**   | - 支持 5000+员工数据量<br>- 关键操作响应时间 ≤1 秒                          |
| **可靠性** | - 数据每日自动备份<br>- 关键操作记录审计日志（增删改）                      |
| **兼容性** | - 支持 Chrome/Firefox/Edge 等主流浏览器<br>- 移动端适配（基础查看功能）       |

---

## **4. 数据模型（关键字段）**
### **员工表（Employees）**
```plaintext
- 工号 (ID) | 姓名 | 部门 | 职位 | 邮箱 | 电话 | 入职日期 | 状态（在职/离职）
```

### **项目表（Projects）**
```plaintext
- 项目ID | 名称 | 负责人 | 开始日期 | 结束日期 | 状态 | 预算
```

### **项目分配表（Assignments）**
```plaintext
- 分配ID | 员工工号 | 项目ID | 角色 | 分配日期 | 释放日期
```
