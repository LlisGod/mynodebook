**user**: 用dataview语法遍历所有标签为undone的文件
[Timestamp: 2025/03/25 00:08:28]

**ai**: 要使用 Dataview 语法遍历所有包含 `#undone` 标签的文件，你可以这样写：

````markdown
```dataview
LIST
FROM #undone
```
````

或更详细的版本（显示文件名和创建时间）：
````markdown
```dataview
TABLE file.ctime AS "创建时间"
FROM #undone
SORT file.ctime DESC
```
````

三个变体说明：
1. `LIST` 最简单，只显示带链接的笔记标题
2. `TABLE` 版本可以展示元数据（如创建时间）
3. 添加 `SORT file.ctime DESC` 会按创建时间倒序排列

注意：
1. 确保你的笔记确实包含 `#undone` 标签
2. 如果标签是嵌套格式如 `#status/undone`，需要改成 `FROM #status/undone`
3. 在 Obsidian 中需要安装并启用 Dataview 插件才能生效
