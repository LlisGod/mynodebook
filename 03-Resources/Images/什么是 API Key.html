API Key 简明指南

API Key 是什么？为什么需要它？

在使用 Obsidian 的 AI 功能前，你需要了解这个重要概念

简单来说：

API Key 就像是一个密码或通行证，让你的 Obsidian 笔记软件能够连接到 DeepSeek 等 AI 服务。 没有这个"钥匙"，AI 功能就无法使用。

如何获取和使用 API Key？

1

注册账号

前往 DeepSeek 官网注册一个账号。如果已有账号，直接登录即可。

2

获取 API Key

在个人设置或开发者选项中找到 API Key 选项，创建一个新的 Key。

3

复制 API Key

点击复制按钮，将这串字符保存下来。注意：这串字符非常重要，请妥善保管！

4

配置 Obsidian

在 Obsidian 的 AI 插件设置中，找到 API Key 输入框，粘贴你的 Key 并保存设置。

深入了解 API

API 全称是"应用程序编程接口"(Application Programming Interface)，它是软件之间沟通的桥梁。

生活中的例子： 想象你去餐厅点餐。你不需要自己跑到厨房告诉厨师怎么做菜，而是通过服务员（API）传达你的需求。菜单就是API文档，告诉你可以点什么菜。

在 Obsidian 中，API 让你的笔记软件能够向 DeepSeek 等 AI 服务发送请求，比如"帮我总结这段文字"，然后接收返回的结果。

API Key 有三个主要作用：

1. 身份验证

证明你有权使用这项服务，就像门禁卡证明你可以进入办公室。

2. 使用限制

跟踪你的使用量，确保不超过允许的限额，就像电表记录你的用电量。

3. 安全保障

防止未授权访问，如果有人滥用服务，可以追踪到是谁的Key。

没有 API Key，AI 服务提供商就无法知道谁在使用他们的服务，也无法控制使用量，这就是为什么几乎所有 AI 服务都需要 API Key。

API 请求的简化流程

Obsidian

1. 发送请求 + API Key
4. 接收AI回答

AI服务器

2. 验证API Key
3. 处理请求

当你在 Obsidian 中使用 AI 功能时，以下是幕后发生的事情：

  1. Obsidian 插件将你的问题和 API Key 打包成一个请求
  2. 这个请求通过互联网发送到 DeepSeek 的服务器
  3. DeepSeek 服务器检查 API Key 是否有效
  4. 如果有效，AI 模型处理你的问题并生成回答
  5. 回答被发送回 Obsidian，然后显示给你

整个过程通常只需几秒钟，但背后涉及复杂的网络通信和安全验证机制。

不同的 AI 服务可能提供不同类型的 API Key，了解它们的区别有助于你选择合适的服务：

免费测试 Key

通常有严格的使用限制，如每天只能发送50个请求，或每分钟3个请求。适合初学者尝试和学习。

付费 Key

根据使用量付费，通常有更高的限额和更好的服务质量。适合频繁使用AI功能的用户。

企业级 Key

提供更高的安全性和可靠性，通常有专门的技术支持。适合商业用途和团队使用。

提示： 对于个人使用 Obsidian，免费测试 Key 通常已经足够。如果你发现经常达到使用限制，可以考虑升级到付费版本。

重要提醒

  • API Key 就像你家的钥匙，千万不要分享给陌生人！
  • 有些 API Key 是免费的，有些则需要付费使用。
  • 如果怀疑 Key 泄露，应立即在官网重新生成一个新的。
  • 不同的 AI 插件可能需要不同的 API Key，请仔细阅读插件说明。

常见问题

API Key 是永久有效的吗？

不一定。有些 API Key 可能有使用期限，有些可能有使用次数限制。建议查看 DeepSeek 官方文档了解具体情况。

使用 API Key 安全吗？

只要妥善保管你的 API Key，不随意分享，一般是安全的。如果担心隐私，可以考虑使用本地部署的 AI 模型，如 Ollama。

我可以在多台设备上使用同一个 API Key 吗？

通常可以，但请注意使用限额是累计的。如果你在多台设备上使用同一个 Key，可能会更快地达到使用限制。

如果我的 API Key 用完额度了怎么办？

这取决于服务提供商的政策。通常有三种情况：1) 等到下个计费周期自动刷新额度；2) 升级到付费计划获得更多额度；3) 创建新的 API Key（但某些服务可能限制这种做法）。

我能用一个 API Key 连接不同的 AI 模型吗？

通常不行。每个 AI 服务提供商（如 DeepSeek、OpenAI、Anthropic 等）都有自己的 API Key 系统。你需要为每个不同的服务分别申请 API Key。
